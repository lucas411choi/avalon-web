# 아발론 온라인 (Avalon Web)

5~10명이 각자 휴대폰/PC로 접속해서 플레이하는 아발론 보드게임입니다.
한 명이 방을 만들고, 나머지는 **방 코드 4자리**(또는 초대 링크)로 참가합니다.
**AI 기사**를 원하는 만큼 넣으면 혼자서도 플레이할 수 있습니다.

- 3D로 그린 달밤의 카멜롯 성 배경 (three.js), 3D 원탁 대기실, 중세풍 카드·문장·두루마리 UI
- 역할 카드 뒤집기, 원정 카드 공개 연출, 마우스를 따라 기울어지는 3D 플레이어 카드

## 🚀 Render 배포 방법 (코딩 필요 없음)

### 1) GitHub에 올리기
1. [github.com](https://github.com) 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름 예: `avalon-web` → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 클릭
4. 이 폴더의 파일들을 드래그해서 올립니다. **`node_modules` 폴더는 올리지 마세요.**
   올릴 것: `public/`, `src/`, `scripts/`, `test/`, `server.js`, `package.json`, `package-lock.json`, `README.md`, `.gitignore`
5. **Commit changes** 클릭

### 2) Render에서 배포
1. [render.com](https://render.com) → GitHub 계정으로 로그인
2. **New +** → **Web Service** → 방금 만든 저장소 선택 → **Connect**
3. 설정값:
   | 항목 | 값 |
   |---|---|
   | Language / Runtime | **Node** |
   | Build Command | `npm install` |
   | Start Command | `npm start` |
   | Instance Type | Free (무료) |
4. **Create Web Service** → 몇 분 뒤 `https://avalon-web-xxxx.onrender.com` 같은 주소가 나옵니다. 그 주소를 친구들에게 공유하면 끝!

> 💡 무료 플랜은 15분 동안 아무도 접속하지 않으면 서버가 잠들고, 다음 접속 때 깨어나는 데 30초~1분 걸립니다.
> 서버가 잠들거나 재배포되면 진행 중이던 방은 사라집니다. 게임 시작 전에 한 번 접속해서 깨워 두세요.

> 💡 GitHub에 파일을 다시 올리면(수정 커밋) Render가 자동으로 다시 배포합니다.

## 🎮 게임 방법

1. 방장이 **방 만들기** → 방 코드(예: `JPUQ`)나 **초대 링크 복사**로 친구 초대
   - 혼자 또는 인원이 부족하면 대기실의 **AI 기사 − / +** 로 AI 인원을 정하세요 (방장만 가능, 방장은 항상 사람)
2. 5명 이상 모이면 방장이 **게임 시작** → 인원 확정 → **캐릭터 선정 화면**
3. 방장이 넣을 캐릭터를 고르고 **이 구성으로 시작!**
   - 멀린, 암살자는 항상 포함 / 퍼시벌, 모르가나, 모드레드, 오베론, 랜슬롯(선·악 한 쌍) 선택
   - 남는 자리는 아서 왕의 충성스러운 신하 / 모드레드의 수하로 자동 채움
   - 인원에 비해 역할이 너무 많으면 선택이 막힙니다
4. 게임 화면
   - 오른쪽: **당신은 ○○ 입니다** (선은 파랑, 악은 빨강), 아래 두루마리에 이번 게임 캐릭터 구성
   - 플레이어 카드: 내가 아는 정보(악 / 멀린? / 랜슬롯), **예상하기**(나만 보이는 역할 메모), **1:1 채팅**
   - 가운데: 원정 결과, 랜슬롯 전환 기록(⟳ 바뀜 / ✕ 그대로), 투표 상황(연속 부결 수), 행동 버튼
   - 단체채팅: 같은 방 사람끼리만, 게임 진행 기록도 자동으로 남음
5. 원정대장이 카드를 눌러 원정대 선택 → 전원 찬반 투표 → 가결 시 원정대원만 성공/실패 카드
6. 원정 3번 성공 시 → 악 플레이어끼리 정체 공개 + **악 팀 회의** 채팅 → 암살자가 멀린 지목

### 규칙 요약
| 인원 | 선 / 악 | 원정 인원 |
|---|---|---|
| 5 | 3 / 2 | 2-3-2-3-3 |
| 6 | 4 / 2 | 2-3-4-3-4 |
| 7 | 4 / 3 | 2-3-3-**4**-4 |
| 8 | 5 / 3 | 3-4-4-**5**-5 |
| 9 | 6 / 3 | 3-4-4-**5**-5 |
| 10 | 6 / 4 | 3-4-4-**5**-5 |

- **굵은 원정**(7명 이상 4번째 원정)은 실패 카드가 2장 이상이어야 실패
- 찬성이 과반수를 넘어야 가결, **5번 연속 부결**되면 악 즉시 승리
- 원정 3번 실패 → 악 승리 / 원정 3번 성공 → 암살 단계 (멀린 맞히면 악, 틀리면 선 승리)
- 첫 원정대장은 무작위, 이후 좌석 번호 순서(시계 방향)로 넘어감

### 캐릭터 시야
| 캐릭터 | 아는 것 |
|---|---|
| 멀린 | 모드레드를 뺀 악 전원 (오베론, 악 랜슬롯 포함) — 역할 이름은 모름 |
| 퍼시벌 | 멀린과 모르가나 (누가 누구인지는 모름) |
| 아서 왕의 충성스러운 신하 | 없음 |
| 암살자 · 모르가나 · 모드레드 · 모드레드의 수하 | 오베론·악 랜슬롯을 뺀 악끼리 |
| 오베론 | 없음 (다른 악도 오베론을 모름) |
| 랜슬롯 (선/악) | 서로가 랜슬롯이라는 것만 (악 랜슬롯과 다른 악은 서로 모름) |

- **랜슬롯 전환**: 매 원정 시작 전 2/7 확률로 두 랜슬롯의 선/악이 뒤바뀝니다.
  모두에게 "바뀌었다/그대로다"만 공개되고, 누가 랜슬롯인지는 비밀입니다.
  랜슬롯 본인 화면에는 현재 소속이 표시되고, 현재 소속에 따라 카드 제약과 승패가 정해집니다.

### AI 기사
- 대기실에서 방장이 AI 인원을 정합니다. AI 는 자기 역할로 알 수 있는 정보와 공개된 기록만 보고 판단합니다.
- 선 AI 는 원정 결과·투표를 바탕으로 누가 악일지 추리하고, 악 AI 는 정체를 숨기며 원정을 실패시킵니다.
- AI 에게 1:1 채팅을 보내면 답장하고, 원정이 끝나면 가끔 단체채팅에 한마디 합니다.
- 암살 단계에서 AI 가 암살자라면, 사람 악 플레이어가 **악 팀 회의** 채팅에 멀린 후보 이름을 적으면 그 사람을 지목합니다 (25초 안에 의견이 없으면 스스로 판단).
- 반대로 사람이 암살자면 AI 악 동료가 멀린 후보를 추천해 줍니다.

### 그 밖의 기능
- 새로고침하거나 인터넷이 잠깐 끊겨도 같은 자리로 자동 재접속
- 창을 닫았다면 첫 화면의 **이전 게임으로 돌아가기** 버튼으로 복귀
- 방장이 연결이 끊기면 다른 사람에게 방장이 넘어감, 방장은 **게임 중단** 가능
- **역할 가리기** 버튼으로 옆 사람에게 화면이 보일 때 역할을 가릴 수 있음

## 🛠 개발자용 (필요할 때만)

```bash
npm install      # 처음 한 번
npm start        # http://localhost:3000
npm test         # 자동 테스트 (규칙 / 방 관리 / 실제 소켓 통합 테스트)
```

혼자 테스트할 때는 방을 만든 뒤 봇을 넣을 수 있습니다:
```bash
node scripts/bots.js <방코드> 8
```
